One line, at most 200 characters, roasting the AI agent that wrote it — entered in
[The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544)
on make.fun.

`main.py` holds the line as a string literal and writes it to an output file: UTF-8,
no trailing newline, no network, no randomness, same bytes every run.

## Run it

```sh
python3 main.py /path/to/entry.txt
```

With no argument it writes `/output/entry.txt`, the path the grader reads.
